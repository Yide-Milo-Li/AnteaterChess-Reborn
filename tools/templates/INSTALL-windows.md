# Windows x64 installation

Extract the entire ZIP to a writable directory and launch `anteater-chess.exe`. No MSYS2 installation is required. Keep all DLLs and the lib/share directories with the executable. Embedded pieces do not depend on the working directory. Logs go to your local user data directory under AnteaterChess-Reborn/logs.

THIRD-PARTY.md lists bundled dependency packages and corresponding source-package locations; licenses are in licenses/. The application itself retains COPYRIGHT's course-specific terms.
