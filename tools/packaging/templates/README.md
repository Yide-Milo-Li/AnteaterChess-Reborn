# AnteaterChess Reborn native runtime

A C++20 / Qt 6 desktop chess variant with Ants and Anteaters on an 8 × 10 board.

See [INSTALL.md](INSTALL.md) for platform setup and the
[user manual](docs/user/manual.md) for current rules and controls. Keep all extracted
files together and run from a writable directory. Logs are stored in `logs/`
beside the actual executable.

[VERSION](VERSION) is the application version. [SOURCE_REVISION](SOURCE_REVISION)
identifies the implementation in this archive; the older published C11/GTK
release can share the same version number. [FILES.sha256](FILES.sha256) covers the
payload, and [DEPENDENCIES.json](DEPENDENCIES.json) records dependency origins,
versions and licenses. Retain the included license notices.

The [historical archive](docs/legacy/README.md) contains the original course
submissions and obsolete implementation records. Current gameplay documentation
is authoritative. The original authors and rights are preserved in
[COPYRIGHT](COPYRIGHT).
